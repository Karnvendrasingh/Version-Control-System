# 🚀 MiniGit - Quick Start Guide

## ⚡ Get Started in 5 Minutes

### 1. **Run MiniGit (Windows)**
```bash

minigit.exe

build.bat

```

### 2. **Try Basic Commands**
```bash
minigit> init
minigit> add test_files/sample.txt
minigit> commit -m "My first commit"
minigit> log
minigit> status

```

## 🎯 Sample Workflow

```bash
# Initialize repository
minigit> init

# Create a test file
echo "Hello World" > myfile.txt

# Add and commit
minigit> add myfile.txt
minigit> commit -m "Add hello world file"

# Modify the file
echo "Hello World v2" > myfile.txt

# Check status and commit again
minigit> status
minigit> add myfile.txt
minigit> commit -m "Update hello world"

# View history
minigit> log

# Go back to previous version
minigit> checkout 1

# Return to latest
minigit> undo
```
