About MiniGit

A simplified version control system that demonstrates core Git concepts

What is MiniGit?

MiniGit is a lightweight, educational version control system implemented in C++ that simulates the core functionality of Git. It's designed to help developers understand how version control systems work under the hood while demonstrating important data structures and algorithms concepts.

Built with modern C++17, MiniGit showcases the use of singly linked lists for commit chains, hash maps for file tracking, and stacks for undo/redo functionality. It provides a hands-on learning experience for anyone interested in understanding version control systems or improving their C++ skills.

Commit History Visualization

See how commits and branches form a version control graph.

What am I seeing?
Each circle is a commit. Lines show parent-child relationships. Colors represent branches. The gold border and 'HEAD' label show your current position. Click a commit for details.
Legend:
  • Blue circle: Commit on main branch
  • Cyan circle: Commit on another branch
  • Gold border: HEAD (current commit)
  • Gray line: Parent-child relationship
  • HEAD: Your current position in the history
  • Branch label: Name of the branch at that commit
